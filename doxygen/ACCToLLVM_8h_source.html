93/// Populate the patterns that remove OpenACC data clause operations once the
94/// constructs holding them have turned their mappings into runtime calls. A
95/// data entry operation is replaced by the address of the object it named, and
96/// a data exit or bounds operation is erased. Clause operations whose result
97/// is not that address stay with the construct that holds them.
98///
99/// A conversion has to populate these only once every construct holding such a
100/// clause operation is lowered in the same conversion, as the mappings would
101/// otherwise be lost.
102void populateACCDataClauseOpPatterns(
103 LLVMTypeConverter &converter, RewritePatternSet &patterns,
104 acc::OpenACCSupport &accSupport, Region &globalSymbolRegion,
105 SymbolTable &symbolTable, const acc::ACCRuntimeCallConfig &config = {});
