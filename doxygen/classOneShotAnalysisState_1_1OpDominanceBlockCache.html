Detailed Description

canUseOpDominanceDueToBlocks walks enclosing regions and queries CFG reachability, but the answer is a property of blocks: every op in a block has the same parent chain, and a definition contributes only its block as a reachability barrier.

One entry per (read block, write block, def blocks) therefore covers every operand pair in those blocks.
