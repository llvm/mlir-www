34/// Returns the size and ABI alignment in bytes.
35///
36/// For aggregate structures and arrays, padding between members or elements is
37/// not taken into account. The result is a close estimate suitable for early
38/// OpenACC layout decisions, but not a complete ABI guarantee. For final size
39/// computations, use LLVM materialized types.
40///
41/// When \p support is provided, aggregate element types are sized by recursing
42/// through \p support so dialect-specific implementations can handle nested
43/// types.
44///
45/// Returns std::nullopt when the size is not statically computable or the type
46/// is not supported.
47std::optional<TypeSizeAndAlignment>
48getTypeSizeAndAlignment(Type ty, ModuleOp module, const DataLayout &dl,
49 OpenACCSupport *support = nullptr);
50
51/// Same as above, obtaining \p dl from \p module via getDataLayout.
52std::optional<TypeSizeAndAlignment>
53getTypeSizeAndAlignment(Type ty, ModuleOp module,
54 OpenACCSupport *support = nullptr);
