73/// Compute the broadcasted runtime size of dimension `dim` of an elementwise
74/// operation whose `operands` all share the same rank (TOSA's
75/// `SameOperandsAndResultRank` and `ResultsBroadcastableShape` traits). The
76/// returned size is either a static `IndexAttr` or an SSA `Value` holding the
77/// runtime size, so dynamic dimensions (fixed rank, unknown size) are handled
78/// correctly. The second element of the pair is the operand that solely
79/// determines the size, or nullptr when it is inferred from several operands.
80/// `indexPool` caches constant index values across calls.
