const MemorySlot & slot,
const SmallPtrSetImpl< OpOperand * > & blockingUses )
static

Returns whether xferOp can be promoted to use or define slot's vector value.

The transfer's memref base must be the slot pointer, its vector type must equal slot.valueType, its indices must be zero, and its permutation map must be the identity. Out-of-bounds dimensions are allowed only for a supported dynamic subview.

More general transfers may be supportable, but their value depends on motivating use cases, implementation complexity, and generated code quality.
