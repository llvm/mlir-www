79/// Check whether the value representing an allocation, assumed to have been
80/// defined in a shared device context, is used in a manner that would require
81/// device shared memory for correctness.
82///
83/// When a use takes place inside an omp.parallel region and it's not as a
84/// private clause argument, or when it is a reduction argument passed to
85/// omp.parallel or a function call argument, then the defining allocation is
86/// eligible for replacement with shared memory.
87///
88/// \see mlir::omp::opInSharedDeviceContext().
89bool allocaUsesRequireSharedMem(Value alloc);
90
91/// Check whether the given operation is located in a context where an
92/// allocation to be used by multiple threads in a parallel region would have to
93/// be placed in device shared memory to be accessible.
94///
95/// That means that it is inside of a target device module, it is a non-SPMD
96/// target region, is inside of one or it's located in a device function, and it
97/// is not not inside of a parallel region.
98///
99/// This represents a necessary but not sufficient set of conditions to use
100/// device shared memory in place of regular allocas. For some variables, the
101/// associated OpenMP construct or their uses might also need to be taken into
102/// account.
103///
104/// \see mlir::omp::allocaUsesRequireSharedMem().
105bool opInSharedDeviceContext(Operation &op);
