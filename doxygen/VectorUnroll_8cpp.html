◆ getTargetShape()

std::optional< SmallVector< int64_t > > getTargetShape ( const vector::UnrollVectorOptions & options,
VectorUnrollOpInterface & iface,
bool allowMasked = false )
static

Return the target shape for unrolling for the given op, provided through its VectorUnrollOpInterface object, iface.

Return std::nullopt if the op shouldn't be or cannot be unrolled. Ops masked by an enclosing vector.mask are rejected unless allowMasked is set, which only patterns that slice the mask for each unrolled op may do.

ATM, target shape can be specified two-fold:

  1. Via VectorUnrollOpInterface (see getDefaultUnrollTargetShape).
  2. Via UnrollVectorOptions (see nativeShape).

Input from a "user" always takes precedence, i.e. 1. is used iff 2. (used for "user" input) is not available.
